# 特性

启动快，热更新快

## esbuild预编译

esbuild 是一个基于 Go 语言的打包工具，它可以将 JavaScript 和 TypeScript 代码编译为浏览器可理解的 JavaScript 代码。原生支持 ES 模块，支持并发，支持增量更新。预构建结果会写入缓存，重复使用


## esmodule，no bundle

现代浏览器原生支持ES module，直接在浏览器完成模块加载荷解析，不需要预先打包。

## 按需加载

在开发模式下，当浏览器请求某个模块时，Vite 会实时解析该模块及其依赖，并将它们作为独立的 ESM 文件提供给浏览器，浏览器将按需加载这些模块。

## 快速热更新


# 资源请求路径

1. 请求拦截

vite serer拦截浏览器请求

2. 解析依赖

解析模块依赖关系，生成对应的module

3. 模块转换

根据文件类型不同确认转换规则，生成不同的esmodule

第三方依赖的 CommonJS、UMD等转换为es module

4. 响应请求

加载执行资源


# 热更新

1. 监听文件变化

Vite 启动时，使用 `chokidar` 文件监听器，监听项目源代码和依赖的变动

2. WebSocket链接

server与浏览器建立 WebSocket链接

3. 发送更新消息

当某个文件发生修改，Vite 服务器通过 WebSocket 向浏览器客户端发送更新通知，通知内容包括改动文件的路径和类型

4. 浏览器端接收消息

浏览器端 `HMR runtime`（内置于 Vite 客户端脚本）收到通知后，决定如何更新模块

5. 模块热替换

浏览器使用原生 ESM 动态 import()，请求更新后的模块代码（单个模块文件）。

模块代码被替换，保持应用状态不刷新整个页面。
