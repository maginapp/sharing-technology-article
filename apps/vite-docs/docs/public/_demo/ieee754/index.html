IEEE 754 特殊数字表示（64位 双精度）

数值 符号位 指数（11 位） 尾数（52 位） 说明
+0 0 00000000000 000...000（全为0） 正零
-0 1 00000000000 000...000（全为0） 负零
+∞ 0 11111111111 000...000（全为0） 正无穷
-∞ 1 11111111111 000...000（全为0） 负无穷
NaN 任意 11111111111 非全为0（如：100...000） 非数字
非规格化数 0 或 1 00000000000 非全为0 用于表示非常接近 0 的小数

注：非规格化数（Subnormal）用于解决“渐进下溢”问题，避免浮点数在接近 0 时直接变为 0。
